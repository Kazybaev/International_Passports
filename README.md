# Passport Lens

Локальное Streamlit-приложение для распознавания загранпаспортов и транспортных документов. В рабочем контуре используется один OCR-движок — RapidOCR ONNX — с независимой повторной проверкой результата.

> Реальные документы и персональные данные нельзя добавлять в Git. OCR выполняется локально и не требует внешнего endpoint или API-ключа.

## Запуск

```bash
make setup
make test
make run
```

Откройте `http://localhost:8501`. Первый запуск может быть медленнее из-за инициализации ONNX-моделей.

Docker:

```bash
docker compose up --build
```

## Повторная проверка

При включённой проверке каждая страница проходит:

1. основной полноразмерный RapidOCR;
2. повторный RapidOCR после локального улучшения контраста;
3. сравнение VIZ-полей и OCR-текста;
4. проверку ICAO TD3 checksum;
5. дополнительные MRZ-кропы только при невалидном результате первых проходов.

Расхождения сохраняются в `provenance.verification` и `decision.reason_codes`. Кнопка «Повторить проверку» заново выполняет оба прохода.

## Что поддерживается

- JPEG, PNG и PDF до 12 МБ;
- число страниц PDF не ограничено;
- до 30 Мп на отдельную страницу;
- quality gate: blur, brightness, glare и resolution;
- паспорта Китая, Узбекистана, России, Турции, Казахстана и Таджикистана;
- ICAO TD3 parser и пять checksum-проверок;
- извлечение VIZ, MRZ и реквизитов транспортных документов;
- раздельное сопоставление нескольких транспортных документов на одной странице или в одном OCR-потоке;
- `accepted / review / retry_capture`, reason codes, provenance и JSON;
- транспортные классификаторы марок и типов.

## Ограничения

OCR и checksum проверяют распознанный текст и внутреннюю согласованность MRZ, но не физическую подлинность документа. Для проверки подлинности нужны NFC/chip и специализированные authenticity checks.

Очень большой многостраничный PDF обрабатывается последовательно, поэтому время работы растёт пропорционально числу страниц. Ограничения 12 МБ на файл и 30 Мп на страницу остаются защитой от повреждённых или чрезмерно тяжёлых файлов.
