# Benchmark на реальных документах

Дата прогона: 2026-08-11. OCR-движок: локальный `RapidOCR ONNX`.

## Конфиденциальность

Документы обрабатывались только локально. Отчёты не содержат имён файлов,
OCR-текста, ФИО, номеров документов, VIN, государственных номеров или иных
распознанных значений. В деталях сохраняются только случайно выглядящий хеш-ID,
наличие полей, checksum-статусы, число OCR-объектов и время обработки.

## Набор

- 385 файлов: 321 PDF, 28 JPEG и 36 JPG;
- 878 страниц с учётом изображений;
- 26 PDF являются пустыми контейнерами без страниц;
- 3 PDF содержат более 20 страниц и не подходят для интерактивной загрузки целиком.

## Целевая проверка техпаспортов

Стабильная партия: 10 реальных китайских свидетельств регистрации.

| Метрика | До настройки | После настройки |
|---|---:|---:|
| Документ ТС обнаружен | 70% | 100% |
| Номер ТС заполнен | 40% | 100% |
| Марка заполнена | 50% | 80% |
| Модель заполнена | 100% | 100% |
| Тип ТС заполнен | 70% | 100% |
| Дата регистрации заполнена | 30% | 100% |
| Среднее число полей | 2,9 из 5 | 4,8 из 5 |

Улучшение достигнуто геометрическим сопоставлением подписи и значения,
поддержкой английских и китайских меток, китайских типов ТС и сопоставлением
распространённых китайских марок с классификатором.

## Целевая проверка загранпаспортов

Из 27 PDF с паспортными названиями 20 не содержали страниц. Проверены все
страницы 7 непустых документов (20 страниц), итог для каждого документа выбран
по лучшей MRZ-странице.

| Метрика | Результат |
|---|---:|
| MRZ найдена | 85,7% |
| TD3 распознан | 85,7% |
| Все MRZ-checksum пройдены | 85,7% |
| Среднее число заполненных MRZ-полей | 6,86 из 8 |

## Смешанная выборка

Детерминированная выборка: 20 файлов, до 2 страниц на файл. Обработано 23
страницы без ошибок; обнаружено 10 страниц с транспортом, 16 паспортных страниц
и 1 страница с обоими типами документа.

- транспорт: в среднем 3,5 из 5 полей;
- паспорт: в среднем 4,25 из 9 полей с учётом обложек и неполных страниц;
- средняя задержка: 5,47 с на страницу;
- p50: 5,27 с, p95: 8,06 с.

## Как интерпретировать точность

MRZ-checksum объективно проверяет внутреннюю согласованность распознанной MRZ,
но покрытие полей не равно exact-match accuracy. Для точной оценки каждого поля
нужен отдельный обезличенный эталонный JSON, проверенный человеком. Реальные
значения нельзя выводить из имени файла или считать эталоном по результату того
же OCR.

Воспроизводимый privacy-safe прогон:

```bash
python benchmark_real_documents.py /path/to/consented/documents \
  --output benchmark_results_real --limit 20 --max-pages 2
```
